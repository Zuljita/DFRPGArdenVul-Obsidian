# Nutri-Vore 2500

## Summary
A technological device used for dispensing medicinal doses of Rudishva aquavit.

It also dispenses nutritional cakes, and the Rudishva aquavit it provides produces no hangovers.

It can be detected as a device within range of a Command Bracelet.
