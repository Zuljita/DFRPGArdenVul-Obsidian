# Yellow Rudishva Identity Plaque

**Canonical pages:**
- [[items/Rudishva Identity Plaque.md|Rudishva Identity Plaque]] (complete guide)
- [[items/Rudishva Identity Cards.md|Rudishva Identity Cards]] (variant catalog)

## Summary
The high-priority yellow credential variant of Rudishva identity plaques. Captain-level access device.

## Properties
- **Access Level:** Captain/high-priority
- **Color:** Yellow
- **Functions:**
  - Opens multiple iris doors in secure areas
  - Activates teleporter panels
  - Bypasses force-field controls
  - Can pacify/suppress some security constructs
- **Primary Location:** [[locations/Rudishva Bastion.md|Rudishva Bastion]]

## Beacon System
- Two yellow captain's plaques were registered in the Beacon system
- Provides full command-level access
