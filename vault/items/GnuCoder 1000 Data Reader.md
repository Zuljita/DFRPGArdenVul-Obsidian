# GnuCoder 1000 Data Reader

## Summary
A portable Rudishva tablet device used for reading data crystals. Inserting a Lesser [[items/Rudishva Power Disc.md|Power Supply Disc]] activates a Rudishva glyph interface; the device then prompts for a data crystal. Two units running simultaneously allow dual video playback.

The party uses the GnuCoder 1000 aboard the [[locations/Beacon.md|Beacon]] as their primary tool for interfacing with recovered Rudishva data crystals.

## Notes
- Requires a **Lesser Power Supply Disc** to operate (not the larger Greater disc).
- Interface language is Rudishva glyphs; non-readers need translation assistance.
- A separate, larger model (**GnuCoder 3000**) exists as a stationary data recorder; the party has one in their armory.
- Oversized GnuCoder units in the [[locations/Cloister.md|Cloister]] library were found powered off and too large to move through a [[items/Teleport Rug.md|Teleport Rug]] (Session 52b/53).
