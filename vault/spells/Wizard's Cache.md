# Wizard's Cache

## Definition

```
Wizard's Cache
Gate 
Regular
Duration: Permanent until dispelled  
Casting time: 10s        
Cost: 2 per pound
Prereq: Blink Other
Hides an object up to 2' in diameter in an extra-dimensional space.  Cannot be found with Seeker, etc.  Leaves a glowing green glyph of the mage's design.  Object can be recalled (at the location of the glyph) with the password or with Dispel Magic.
```
