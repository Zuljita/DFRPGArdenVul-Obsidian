# Cloister

## Summary
A location within the campaign world used as part of a traversal route and identified for security prioritization.

It is a Rudishva cloister located near the Beacon.

A teleporter in a Rudishva command chamber south-east of the Beacon area leads to this location.

A secret passage leads from the Cloister to a slime pit room.

The secret passages from this location lead toward the Behir caves.

Moving west from the Cloister leads to an acidic pool room and a room containing Chaotic Sweat.

The Cloister library contains oversized GnuCoder units that are too large to be moved via Teleport Rug.

Secret passages from this location proceed southwest, then north along water, and then east.

The cloister teleporter, when used with the treasury's yellow-ID teleporter, provides an indoor route from the Beacon to the known Halls.

The oversized GnuCoder units in the library were found powered off.

A one-way door leading to the Cloister level was propped open during Session 47.
