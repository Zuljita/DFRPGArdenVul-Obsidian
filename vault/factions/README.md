# Factions

- Create one file per faction.
- Use the template in `vault/templates/Faction Template.md`.
- Name files in Title Case (e.g., `[[factions/Cult of Set.md|Cult of Set]].md`).

Suggested front matter:
---
title: [[factions/Cult of Set.md|Cult of Set]]
tags:
  - faction
  - faction
aliases: []
---
