# Troll Pits
*Data crystal*

## Summary
A work in Rudishva. Apparently the Rudishva set up some pits full of neuroderm somewhere in the Halls where the Rudishva could make varumani.   If this is true, varumani are Rudishva constructs, not natural life forms.  There are matrix cards containing settings for 3 models, called A (Vanara), D (Druva), and G (Rudiga).
