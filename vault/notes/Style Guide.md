# Style Guide

## Spell references

- For stock/RAW spells that are not maintained as local vault pages, use **plain text in italics**.
- Example: *Lockmaster*, *Walk on Air*, *Invisibility*.
- Do **not** use wiki links for these stock spells.

## Alias behavior

- Prefer canonical pages with alias redirects (frontmatter `aliases`) over one-line alias stub pages.

## Session titles

- Use concise session titles in frontmatter, e.g. `31: I Want to Believe`.
- Avoid prefixing with `DFRPG Arden Vul Session ...`.
